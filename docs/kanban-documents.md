# PDF и сканы в Kanban

В форме «Сформировать задание» можно выбрать PDF, JPEG или PNG до 25 МБ. Для PDF допускается до 50 страниц.

1. Нажмите «Распознать PDF / скан». Страницы обрабатываются последовательно; есть автоповорот и выбор угла вручную.
2. Откройте исходные страницы и сверьте таблицу. OCR извлекает кандидаты маркировок, а не гарантированно точную копию задания. Исправьте ошибки, исключите лишнее и добавьте пропущенные строки. Дополнительные поля можно заполнить вручную. Уверенность OCR не означает достоверность связи с базой.
3. Нажмите «Строки проверены», затем «Анализировать файл». Проверьте найденные, отсутствующие, неоднозначные позиции и расхождения с генеральной базой. При изменении строк анализ сбрасывается.
4. Подтвердите импорт найденных кабелей. Создаётся карточка в столбце подразделения; оригинал появляется во вложениях. Отсутствующие и неоднозначные позиции не импортируются — это видно перед подтверждением.

PDF/сканы доступны заказчику (ТАИ → «Задачи заказчика»), монтажу (СКМ → «В монтаже») и наладке («Список в наладке»). Загрузка разрешена только в свой столбец, включая пользователей с административной ролью. Сервер повторно проверяет текущий столбец при сохранении вложения. Правила административного перемещения карточек и существующего Excel-импорта остаются прежними. При создании нового списка монтажа загрузивший сотрудник становится ответственным.

В открытой карточке раздел «Вложения» позволяет добавить PDF/JPEG/PNG без распознавания и без изменения кабелей или готовности. Это действие доступно только в своём столбце. Скачивать вложения могут авторизованные пользователи, которым доступна общая доска. Файл скачивается через сервер, без публичного S3 URL.

Цвета игнорируются. Плюсы означают выполненные комнаты, однако автоматическая запись прогресса по ним не выполняется: при создании списка ни наличие кабеля в задании, ни плюс, ни дата не устанавливают готовность. Даты и рукопись требуют проверки; нераспознанные поля не заполняются догадками.

Распознавание работает на устройстве через существующий Tesseract и PDF.js; документ не отправляется во внешний AI API. Для первого запуска нужно загрузить OCR-активы с сервера. Не гарантируется распознавание любой рукописи, любого шаблона и всех строк. Ошибки отдельных страниц показываются явно; перед подтверждением частичного результата пользователь должен проверить оригинал. Отмена останавливает обработку после текущей OCR-операции.

Для сохранения оригиналов требуется `S3_UPLOADS_ENABLED=true` и настроенный S3 по [storage.md](storage.md). При отказе архива карточка/вложение не фиксируется как успешно сохранённое. Попытка архивируется до транзакции, затем привязывается к карточке; неуспешная попытка может остаться в приватном архиве, но не отображается как вложение. Повтор файла в одной карточке не создаёт второе вложение. Очистка истории событий не удаляет связь вложения с существующей карточкой; после удаления карточки архив не выдаётся как её доступное вложение.
