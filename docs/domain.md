# Предметная область

| Термин             | Значение / источник                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| Генеральный кабель | Стабильная сущность `cables`; ключ «журнал + номер», иначе нормализованные марка/направление (`import.server.ts`)      |
| Снимок карты       | `import_snapshots` и `imported_cable_rows`; активный снимок для demolition/installation                                |
| Прогресс           | Целое 0–100%; генеральное значение `cables.progress` и исторические значения `cable_progress`                          |
| Группа / помещение | Графические агрегаты `graph_groups`, `graph_group_rooms`; ручные помещения хранятся отдельно                           |
| Список Kanban      | `priority_room_lists` с позициями `cable_list_items`; существует независимо от активной карты                          |
| Этапы              | formed → in_progress → curator_review → adjustment → done; возврат и разделение предусмотрены workflow                 |
| Подразделения      | ТАИ, СКМ, наладка, куратор (`auth/shared.ts`)                                                                          |
| Монтажная доска    | Отдельные `installation_snapshots`, `installation_kks_groups`, `installation_kks_items`; не тождественна карте монтажа |
| Офлайн-изменение   | Браузерная очередь → `installation_pending_changes` → ручное утверждение                                               |
| Замечание          | Текст и адресация к списку/позициям/изменению; связи `remark_cable_items`                                              |

Источники правил: README, `src/lib/auth/shared.ts`, `src/lib/cable-map/shared.ts`, `src/lib/installation/shared.ts`, `src/lib/db/schema.ts`. MASTER может выбирать этапы; СКМ принимает список, назначается ответственным и отмечает позиции; ТАИ/куратор проверяет и разделяет; наладка завершает свой этап. Проверять права на серверной границе. Обычные пользователи не получают административные права через скрытый UI.

Числа: прогресс — проценты, длина — метры, сечение — мм², масса — кг; расчет меди использует 0.00889 кг/(м·мм²) в `queries.server.ts`. Даты истории — YYYY-MM-DD, рабочая дата — Europe/Moscow (`report-utils.ts`), временные метки передаются ISO. Нормализация визуально одинаковых кириллических/латинских букв участвует в идентичности; OCR использует отдельную нормализацию.

Инварианты для проверки: смена ревизии защищает от потерянных изменений; повтор запроса не создает дубликат; офлайн-запись относится к своему снимку и автору; принятое разделение не создает новые генеральные кабели; отображение и сохранение используют согласованный прогресс. Исходные нарушения описаны в `tasks/2026-10-25-review/findings.md`; исправления и проверки текущей версии — в `tasks/2026-10-25-fixes/completion.md`.

Неизвестны утвержденные пределы объемов, политика хранения снимков/кэшей и точность инженерных расчетов. Они требуют источника требований перед изменением соответствующего поведения.
