# Spider Viewer: контекст

Обследование: 2026-10-25, исходники `bee18d9`, исходное пользовательское изменение — `.gitignore` (игнорирование `.private/`). Источники: `README.md`, `package.json`, `src/routes/`, `src/lib/`, `scripts/`, схема БД. Документ отражает карту и проверенные пути, а не построчный аудит всего приложения.

Приложение предназначено для просмотра и учета прокладки/демонтажа кабелей РОАЭС. Пользователи импортируют Excel/ODS, просматривают карту, изменяют готовность, передают списки по этапам Kanban, ведут замечания и экспортируют историю в DOCX. Отдельная доска монтажа поддерживает KKS, офлайн-очередь и распознавание фотографий в браузере.

Критичные исходы: отсутствие потери прогресса; правильная идентификация кабеля; соблюдение ролей и подразделений; сохранение истории; безопасная повторная синхронизация. Их источники — описание сценариев в README и контракты схем/валидаторов; обнаруженное несоответствие реализации фиксируется как дефект, а не переопределяет требование.

Стек: Bun, TypeScript, React, TanStack Start/Router, Vite, Drizzle/PostgreSQL, Redis, IndexedDB, Service Worker, Tesseract. PostgreSQL — основное серверное хранилище. Redis используется как вспомогательный кэш истории. Переменные окружения перечислены в `.env.example` и README; значения секретов не включать в документы.

Владелец требований и исключений — владелец репозитория. Не установлены численные SLO, типичный размер базы, поддерживаемые устройства и браузеры, требования к офлайн-доступу после выхода и фактические настройки production. В коде есть комментарий об исходных файлах на 26 тысяч строк; это основание проверить большой импорт, а не установленный предел продукта.

Текущая задача: аудит без исправления прикладного кода и подключение Swiss Clock по прямому запросу пользователя. Деплой, миграции рабочей БД и публикация результатов не входят в задачу.

Исправления по результатам аудита и миграция на Bun >=1.4.4 выполняются по прямому запросу владельца в `tasks/2026-10-25-fixes/`. Актуальные команды проверки — `docs/verification.md`; первоначальные ограничения окружения в отчете аудита являются историческими.
