# Layout приложения

Статус: реализовано, проверка не завершена.

Источник: запрос пользователя и два скриншота. Риск обычный.

AC-01: сайдбар плавно меняет ширину одновременно с контентом; переключатель в шапке, область rail отсутствует.
AC-02: верхняя панель отсутствует, нижние хлебные крошки не перекрывают содержимое, без бордера и заливки.
AC-03: страницы имеют верхний отступ без дополнительной полосы фона журнала.

Поток: маршрут → AppShell → прокручиваемая область страницы и отдельный нижний блок. SidebarProvider управляет шириной, className не должен перекрывать transition width.
Сценарии: раскрытый/свернутый sidebar; короткая/длинная страница; скрытый chrome карты. Серверные контракты, данные и миграции не затронуты.
