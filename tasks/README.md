# Артефакты задач

Для задачи создайте `tasks/<task-id>/task.md` и `completion.md` по шаблонам `.agent/templates/`. Идентификатор должен быть стабильным; допускается ID внешнего трекера.

Карточка хранит цель, источники, AC, область влияния, риски и план проверок. Отчет хранит связь критериев с результатами на конкретном состоянии. Не копируйте полные логи и историю рассуждений: оставляйте информацию для проверки и продолжения работы.

Для локальных правок текста без изменения правил допустим короткий отчет в ответе вместо отдельной папки, согласно `AGENTS.md`. Изменение протокола требует карточки. Не храните секреты или чувствительные фикстуры.
