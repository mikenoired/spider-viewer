## Потоки и инварианты

Подробная карта: `docs/architecture.md`. Аудит проходит входы createServerFn → guards → запросы/мутации → PostgreSQL → UI; импорт workbook → нормализация → bulk insert; IndexedDB → pending → утверждение; GET → Service Worker → Cache Storage. Инварианты: авторизованное чтение, переходы по правам, атомарные версии, сохранение отображаемого прогресса, изоляция очереди по снимку/автору, ограничение ресурсов.

## Решение и проверки

Перенести только протокол и контекст; сохранить аудит и небольшой автономный reproducer. Новые зависимости не нужны. Отдельный архитектурный ADR не требуется: runtime не меняется. Проверки для этого diff: локальные ссылки, целостность переноса, `git diff --check`, состояние прикладных tracked-файлов, формат новых поддерживаемых файлов. Исходные запуски тестов и границы воспроизведения сохраняются без объявления полного зеленого CI.

Неизвестное: реальный production размер/latency, browser compatibility, требования к очистке после logout, защита веток. Никакие изменения поведения на основе этих неизвестных не выполняются. Независимое ревью не проведено и не подменяется самопроверкой. Для публикации изменения правил приемки требуется ревью владельца; текущая задача — подготовить локальный reviewable diff.
