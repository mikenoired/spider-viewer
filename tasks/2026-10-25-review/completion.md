## Ограничения и следующий шаг

Полные проверки приложения не завершены: нужен согласованный frozen install и повтор V-01–V-03 из `docs/verification.md`. Для проверки конкурентности/SQL нужна disposable PostgreSQL; DB doubles не доказывают контракт реального драйвера и изоляцию транзакций. Для UI/офлайн/OCR нужен браузерный прогон; для performance — измерения на репрезентативном объеме и latency. Оценка F-12 при 10 мс RTT — расчет, не замер.

Правила приемки и защиты веток не включаются одним AGENTS.md. Branch protection, контролируемое падение GitHub CI и независимые eval-прогоны не проверены. Источники секретов и рабочие данные в артефакты не включались. Откат локального подключения — удалить только новые файлы этой задачи и добавленный README-абзац, сохранив пользовательский `.gitignore`.

Статус: **реализовано, проверка не завершена** для полной приемки приложения. Локальное подключение протокола проверено, отчет аудита предъявлен. Следующее действие владельца/следующей задачи: восстановить dev-зависимости из lock-файла, выполнить полный набор и выбрать находки для исправления; не публиковать текущее приложение как проверенное на основании этого отчета.
