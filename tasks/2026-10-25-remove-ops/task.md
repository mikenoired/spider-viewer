# Удаление устаревшей VPS-инфраструктуры

Статус: завершено.

Источник: пользователь подтвердил удаление инфраструктуры Ubuntu/VPS, поскольку приложение запускается на Railway. База: `12fa41f`, рабочее дерево чистое. Риск низкий: `ops` исключена из Docker-контекста, активных вызывающих сторон вне самой папки нет.

## Критерии приемки

- AC-01: удалить все семь отслеживаемых файлов `ops` и упоминание в актуальной карте архитектуры; убрать ненужное исключение Docker.
- AC-02: сохранить Railway-путь `railway.json` → `Dockerfile` → `scripts/predeploy.mjs` / `scripts/serve.mjs` без изменений.

## Область и проверки

Удаляются только неиспользуемые VPS-скрипты, Nginx и systemd-конфигурация. Данные и внешние серверы не затрагиваются. Восстановление возможно из Git. Входные данные, конкурентность, численные границы и частичные отказы runtime неприменимы: активный код приложения не меняется.

Проверки: поиск оставшихся ссылок; сравнение активных конфигураций с базой; `git diff --check`; `bun run lint:check`. Полный build и тесты runtime не требуются для удаления файлов, ранее исключенных из Docker-контекста. Самопроверка diff по требованиям и реализации; независимое ревью для этого риска не обязательно.
