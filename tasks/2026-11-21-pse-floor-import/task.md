# Группировка помещений ПСЭ‑2 по отметкам

## Цель и основания

Вернуть компактную карту демонтажа при импорте ПСЭ‑2. Первый прототип `8e32bfd` группировал помещения по отдельной колонке отметки исходного листа «Общ». Адаптер ПСЭ‑2 использует высоту оборудования `Z начало` в качестве отметки. На исходной книге 7 326 строк дают 207 уровней.

Источники правил — три расшифровки от 20 ноября. В первом звонке в 06:52–13:10 приведены отметки, в 13:12–14:32 уточнена принадлежность границы к верхнему этажу, в 14:39–16:22 перечислены отметки и промежуточная площадка. Во втором звонке в 00:31–01:13 подтверждена площадка 19,2. В третьем в 00:00–04:01 указаны отдельные отметки гермообъёма и префикс ГА. Классификация зон и машзала в третьем звонке оставлена на последующее уточнение.

Риск обычный. Изменение создаёт новый снимок обычным импортом. Исторические снимки и исходные данные остаются доступны приложению на прежних условиях. Подготовка миграции архивных снимков и публикация за пределами задачи.

## Исходное состояние

База `0ef8b1368d525c0cb35f0c50a2099695ef5f9250`. В рабочем дереве есть отдельные изменения OCR и карточки задачи от 19 ноября. Форматтер и проверки выполняются на Bun 1.4.4. Книга найдена локально в «Загрузках». Источника соответствия каждого помещения проектной отметке нет.

## Критерии приёмки

| ID    | Ожидаемый результат                                                                                                                                                                                                            | Доказательство                                                      |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| AC-01 | ПСЭ‑2 использует ограниченный перечень отметок. Точная нижняя граница относится к этажу, который с неё начинается. Для кодов ГА применяется перечень гермообъёма.                                                              | Синтетический Excel с границами, незаполненным Z, точкой и запятой. |
| AC-02 | Каждое помещение имеет одну отметку. Высоты начала и конца сопоставлены со своим помещением. Помещения назначения отображаются в том числе без исходящих кабелей. У пропусков и неразрешимых конфликтов одна отдельная полоса. | Парсер, запись и чтение карты на отдельной PostgreSQL.              |
| AC-03 | Состав и идентичность кабелей сохраняются. Помещения назначения отображаются без повторного учёта кабелей. Переимпорт сохраняет генеральный прогресс.                                                                          | Повторный импорт на отдельной БД и сверка исходной книги.           |
| AC-04 | Форматы «Общ» и монтажной книги читаются по прежним правилам.                                                                                                                                                                  | Существующие тесты парсера и интеграции.                            |

## Область влияния

Адаптер книги передаёт рассчитанную отметку в группировку. Агрегаты и выбранный снимок записываются транзакцией. Запрос карты собирает полосы из сохранённых групп. Существующие роли помещений отделяют рабочие комнаты начала от комнат назначения. Настройка в метаданных нового снимка включает показ назначения, сохраняя поведение прежних форматов и снимков. Канонический ключ и редактирование прогресса остаются привязаны к исходной строке.

| Сценарий                      | Правило                                                                                                                                                                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Обстройка                     | Отметки −4,2, 0, 3,6, 6,6, 13,2, 16,6, 19,2, 24, 24,6, 28,8, 33,6, 36,6, 41,4, 45,6. Верхняя граница 50,4.                                                                                                                                                   |
| Гермообъём                    | Для ГА отметки 13,2, 19,34, 25,7, 29,4, 33,6, 36,6. Верхняя граница около 45. Значения 19,34 и 45 взяты из автоматической расшифровки как рабочая интерпретация.                                                                                             |
| Промежуточная высота          | Используется наибольшая начальная отметка по таблице. 10,8 звучит как верхняя граница пролёта и отсутствует в итоговом списке этажей. Помещения с Z от 10,8 до 13,2 продолжают отображаться на 6,6. Площадка 19,2 сосуществует с явно названной отметкой 24. |
| Несколько Z в одном помещении | Голос для отметки даёт каждое числовое наблюдение в пределах диапазона. Выбирается отметка с наибольшим числом голосов. При равенстве лидеров либо отсутствии допустимых высот используется «Уровень не указан».                                             |
| Верхняя граница и выбросы     | Координата за пределами диапазона не создаёт этаж. Если у того же помещения есть допустимые наблюдения, этаж можно определить по ним.                                                                                                                        |
| Нет помещения начала          | Кабель остаётся в исходной строке. Если указано помещение назначения, оно отображается по своей отметке.                                                                                                                                                     |

## Проверки

`bun run lint:check`, `bun run test`, `bun run build`, интеграционные проверки по [регламенту](../../docs/verification.md), `git diff --check`. Сверить исходную книгу на изолированной БД. После реализации проверить требования и diff отдельно. Проектные отметки конкретных комнат можно подтвердить только независимым справочником помещений.
